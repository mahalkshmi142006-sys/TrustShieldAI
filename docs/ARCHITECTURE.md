# TrustShieldAI Architecture
LLM: question + response -> claims -> evidence retrieval -> verification -> Q/A consistency -> trust/risk/confidence.
Media: image/video -> OpenCV -> forensic indicators -> screening risk.
Identity: reference + probe -> face detection -> lightweight descriptor -> similarity.
The media and identity components are prototype baselines, not validated production biometric or state-of-the-art deepfake detectors.
